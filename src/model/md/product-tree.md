# Product Tree

## Purpose

This notebook describes the hierarchical structure of the Agricultural Earth Observation Satellite: the satellite, its main subsystems, and the physical parts belonging to each subsystem.

## Design Rationale

The satellite is decomposed into five main subsystems. Each subsystem contains physical parts that contribute to its functions. This decomposition helps the concurrent design team understand subsystem boundaries and identify the physical parts associated with each subsystem.
